# Build standards

The process and the plain-language reference behind every app I build, work or personal. Each APP project in Claude links to the files here, so a change is made once.

| File | What it is |
| --- | --- |
| `app-build-sop.md` | The App Build SOP: how apps go from idea to release and beyond. Exported from the Claude Doc "App Build SOP" |
| `concepts-handbook.md` | The ideas that repeat across apps, each explained once in plain language, with a glossary |

**Updating the SOP:** edit the Claude Doc, export it to Markdown, replace `app-build-sop.md` here, and commit with a message saying what changed.
